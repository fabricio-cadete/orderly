# Roadmap

1. **Fase 1, essencial**: autenticação, tarefas, projetos e categorias, prioridades, datas, Hoje e Em breve, sincronização.
2. **Fase 2, produtividade**: recorrência, lembretes, subtarefas, calendário semanal, modo offline, atalhos.
3. **Fase 3, Apple**: Apple Watch, widgets do iPhone e do macOS, Siri.
4. **Fase 4**: linguagem natural, hábitos, Pomodoro, estatísticas, integração com calendários.
