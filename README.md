# Orderly.

**Less chaos. More clarity.**

App de tarefas multiplataforma: iPhone, Apple Watch, widgets, Windows, macOS e web, todos sincronizados por uma única API.

```
apps/        mobile (Expo) · desktop (Tauri) · web (React) · watch (SwiftUI)
packages/    ui (tokens de design) · core (domínio) · api-client
backend/     ASP.NET Core .NET 10 · PostgreSQL · SignalR
infrastructure/  Docker
docs/        arquitetura, roadmap, como começar
```
